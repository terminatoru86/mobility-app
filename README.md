# MOBIlity — M1 (demo)

Map of Chicago with status pins, compass clusters, place sheets with the rotating
vehicle tile, the 8-step guide and the account invite. Demo data, no Firebase yet.

## Cum o pornești (Windows + Android Studio)
1. Android Studio → New Flutter Project → Flutter → nume: `mobility` → Create.
2. Închide Android Studio. Dezarhivează zip-ul și copiază peste proiect:
   `lib/`, `assets/`, `test/`, `pubspec.yaml`, `analysis_options.yaml` (înlocuiește tot).
3. Deschide proiectul → în bara de sus apare **Pub get** → apasă-l.
4. Telefon: Setări → Despre telefon → apasă de 7 ori pe „Număr versiune” →
   Opțiuni dezvoltator → **Depanare USB** pornit. Conectează cablul, acceptă pe telefon.
5. Alege telefonul în lista de dispozitive și apasă ▶ Run.
6. Dacă apar erori roșii, copiază-le și trimite-le în chat.

Test: Profile → „Reset demo” ca să vezi din nou ghidul; invitația de cont apare la a 3-a pornire.
